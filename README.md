#  Nutrition Planner — казахская кухня

Персональный планировщик питания, который строит план приёма пищи на несколько дней с рецептами казахской кухни — с учётом целей по весу, активности и режима дня пользователя.

## Возможности

- Расчёт целевых КБЖУ (калории, белки, жиры, углеводы) на основе пола, возраста, роста, веса и целевого веса
- Автоматическое построение расписания приёмов пищи (подъём, завтрак, перекус, обед, ужин, поздний перекус, сон) под индивидуальное время подъёма и сна
- Рекомендация блюд из базы казахских рецептов через косинусное сходство между целевыми КБЖУ и параметрами блюд
- Подбор без повторов — система не предлагает одно и то же блюдо слишком часто
- Расчёт дефицита/профицита калорий по дню и рекомендации по корректировке порций
- Просмотр подробностей конкретного рецепта (состав, шаги приготовления, время готовки)

## Стек технологий

**Backend**
- Python, FastAPI, Uvicorn
- Pandas, NumPy
- scikit-learn (MinMaxScaler, cosine similarity)

**Frontend**
- React 19 + Vite
- React Router 7
- ESLint

**Данные**
- `kazakh_recipes.csv` — 142 рецепта казахской кухни
- `RAW_recipes.csv` — 231 637 рецептов (использован при разведочном анализе)
- Модели (`kbzhu_model.pkl`, `recommender_vectors.pkl`) — хранятся через Git LFS

## Запуск проекта

### Backend

```bash
cd api
pip install -r requirements.txt
uvicorn main:app --reload
```

Сервер поднимется на `http://localhost:8000`.

### Frontend

```bash
cd frontend
npm install
npm run dev
```

## API

| Метод | Эндпоинт | Описание |
|---|---|---|
| GET | `/` | Проверка работоспособности сервера |
| POST | `/generate_plan` | Генерация плана питания по профилю пользователя |
| GET | `/recipe/{dish_name}` | Подробности рецепта по названию |
| GET | `/activities` | Список уровней активности для формы |

### Пример запроса на `/generate_plan`

```json
{
  "gender": "female",
  "age": 22,
  "height": 165,
  "weight": 60,
  "target_weight": 55,
  "activity": "moderate",
  "wake_time": "08:00",
  "sleep_time": "23:00",
  "plan_days": 7
}
```
